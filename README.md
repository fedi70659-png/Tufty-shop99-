# TUFTY — Custom Tufting

A simple modern static website for GitHub Pages.

## Publish
1. Create a GitHub repository, for example `tufty-store`.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated GitHub Pages URL.
